Automatic CCD Tracking TCD1304DG
How automatic mode works

A small mirror picks off ~1–2% of the beam and directs it onto the TCD1304DG linear CCD sensor (3648 pixels). The sensor measures how much light it receives. When the diffraction crystals are at the correct angle for the target wavelength, the beam is aligned and the CCD sees maximum intensity.

Typical workflow:
  ① Seek Home, then move the motor to approximately the middle of the travel range (~16°) so the crystals can go both CW and CCW.
  ② Manually find the correct crystal position for each wavelength and save it to the calibration table (Record / Calibrate tab).
  ③ Use Go to λ to jump to the lookup-table position. Due to mechanical tolerances there is usually a ±300–1000 step error.
  ④ Click Start Auto-Track. The motor fine-tunes around the lookup-table position to find the true intensity peak, correcting the mechanical error.
  ⑤ When the lab changes wavelength, intensity drops. Auto-track detects the drop and re-searches for the new peak automatically.

The system works in three phases:
  ① Initial search — immediately on start, the motor dithers CW and CCW to find which direction gives more intensity, then walks that way until intensity peaks. This finds the optimal crystal angle for the current wavelength.
  ② Track — the motor holds position and keeps reading the CCD every 200 ms. When intensity is stable, nothing moves.
  ③ Re-search — if intensity drops by more than the drop threshold (default 5%), the wavelength has changed and the crystal is misaligned. The motor automatically searches for the new peak angle.

Important: run Seek Home first. For this to work the CCD must not be saturated — if the graph shows a flat top at max, reduce the laser power or increase distance so you see a clear peak, not a filled bar.

Drop threshold (currently shown above) = how much the intensity must fall before the system decides the beam has moved and starts searching again.
Example: if best intensity was 50000 and threshold is 5%, a drop below 47500 triggers a new search.
For optical alignment, 5% is a good starting point. Increase to 10–20% only if vibrations cause false re-searches.

⚡ TRIGGER WIRING — READ BEFORE CONNECTING

D12 uses the Arduino's internal pull-up resistor — no external resistor needed. The pin idles HIGH and fires on a falling edge (HIGH → LOW).

Connect your 2-wire lab cable:
  • Cable trigger wire (pulse output) → Arduino D12
  • Cable GND → Arduino GND (the GND pin next to D13/AREF is fine)

Each time the cable pulls D12 LOW → one scan step fires. The 50 ms debounce prevents double-fires.

🟢 D13 (built-in LED) is the Arduino's own power-on LED. Do not wire anything to D13.

Testing with a bench power supply:
  1. Connect supply (−) to Arduino GND.
  2. Arm the scan first, then briefly touch the supply (−) wire to D12 to simulate each trigger pulse (pulling it LOW).
  3. Do not connect supply (+) to D12 — the pin is already pulled HIGH internally.
